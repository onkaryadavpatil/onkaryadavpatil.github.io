Privacy Policy

BITSIZE ENGLISH Publisher. Last updated: 5 October 2026.

BITSIZE ENGLISH Publisher is a personal tool used only by the owner of the BITSIZE ENGLISH YouTube channel. This policy explains what the tool accesses in the owner's Google account.

What the tool accesses

  • YouTube: it uploads the owner's videos to the owner's own channel, sets their thumbnails, and reads the status of the owner's own uploads.
  • Google Calendar: it creates one secondary calendar in the owner's Google account and adds, changes and removes events on that calendar only. It cannot see or change any other calendar.

What is stored and where

The Google sign-in token (a refresh token) is stored in a private file on the owner's own computer. The tool has no server and no database. Video files, scripts and schedules stay on the owner's computer, apart from what is uploaded to YouTube or written to the calendar.

Sharing

The tool does not collect data from anyone else. It does not sell, rent, share or disclose Google user data to any third party, and it does not use it for advertising.

YouTube API Services

This tool uses YouTube API Services. By using it, the owner is bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
